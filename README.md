🌍 Explore the World — One Country at a Time

This project highlights advanced UI design, reusable component architecture, responsive styling with SCSS, and efficient API data handling, making it a strong showcase of frontend development skills.

✨ Project Overview

Explore the World is an interactive atlas designed to provide meaningful insights about countries in a visually engaging way. Users can browse detailed country information such as:

🌆 Capital cities

👥 Population statistics

🏳️ Country flags

📖 Interesting facts and descriptions

The application presents information using dynamic country cards, smooth navigation, and dedicated detail pages to create an engaging exploration experience.

🧭 Key Features
🗺️ Country Exploration

Browse countries displayed as interactive cards

View key information including capital, population, region, and flag

“Read More” functionality to open a detailed country view

🔍 Search, Filter & Sorting

Real-time search functionality to find countries quickly

Filter by continent for region-based discovery

Sort countries in ascending or descending order by name

📄 Country Detail Page

Dedicated descriptive screen for each country

Clean and structured layout for better readability

📬 Contact Section

Contact form allowing users to reach the website administrator

🎨 UI/UX & Design

High-end, modern, and minimal interface

Fully responsive design across mobile, tablet, and desktop

Built with SCSS for scalable and maintainable styling

Reusable, modular React components

Smooth navigation and user-friendly interactions

Focus on accessibility, clarity, and performance

🔌 Data Handling

Country information fetched from an external API

Efficient rendering and state handling

Clean separation of UI components and business logic

Optimized data flow for smooth performance
